# Meu Portfólio Pessoal

Bem-vindo ao meu portfólio! Este projeto foi desenvolvido para demonstrar minhas habilidades, projetos e serviços. 

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias modernas:

*   **[Next.js](https://nextjs.org/) (v15 App Router):** Framework React para renderização do lado do servidor, otimização de rotas e SEO.
*   **[React](https://react.dev/) (v19):** Biblioteca JavaScript para construção da interface de usuário.
*   **[Tailwind CSS](https://tailwindcss.com/):** Framework CSS utilitário para estilização rápida e responsiva, com suporte a **Dark Mode** customizado.
*   **[Motion (Framer Motion)](https://motion.dev/):** Biblioteca para animações fluidas e interativas na web.

## 🏗️ Estrutura do Projeto

O portfólio é modular e composto por diversos componentes reutilizáveis, garantindo um código limpo e fácil de manter:

*   **`Navbar`**: Navegação principal com suporte a tema claro/escuro.
*   **`Header`**: Seção de introdução/hero.
*   **`About`**: Detalhes sobre mim e minha jornada.
*   **`Services`**: Serviços que ofereço.
*   **`Work`**: Galeria de projetos desenvolvidos.
*   **`Contact`**: Formulário/links para contato.
*   **`Footer`**: Rodapé com links e informações adicionais.

## 🎨 Design e Estilização

O design foi pensado para ser moderno e acessível:
*   **Fontes:** Utiliza as fontes `Outfit` (sans-serif) e `Ovo` (serif) para uma tipografia elegante.
*   **Tema:** Paleta de cores customizada com tons específicos para hover (`lightHover`, `darkHover`) e um modo escuro imersivo (`darkTheme`).
*   **Animações:** Transições suaves entre seções e micro-interações em botões e cards utilizando o Framer Motion.

## ⚙️ Como rodar o projeto localmente

1. Clone o repositório.
2. Instale as dependências com `npm install` (ou `yarn`, `pnpm`, `bun`).
3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```
4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
